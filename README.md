# YouTube Interface · HTML and CSS Study

A static YouTube-style interface built to practice page layout, reusable visual patterns, and responsive video-card grids. The repository also includes smaller HTML/CSS exercises for individual layout concepts.

**HTML5 · CSS3 · Grid · Flexbox**

[Portfolio](https://github.com/kuvlay)

## What is included

- A header with search and action controls.
- A navigation sidebar.
- Video cards with thumbnails, channel images, titles, and metadata.
- Separate stylesheets for the header, sidebar, video grid, and general styling.
- Focused exercises covering grid, flexbox, positioning, display behavior, and image/input layout.

## View locally

```bash
git clone https://github.com/kuvlay/youtube-clone.git
cd youtube-clone
```

Open `youtube.html` in a browser. There is no npm dependency, environment configuration, or build step. Google Fonts requires an internet connection; the main images and icons are stored locally.

## Key files

| Path | Purpose |
| --- | --- |
| `youtube.html` | Main interface |
| `styles/` | Component-level CSS |
| `youtube-thumbnails/`, `profile-pic/`, `icons/` | Local visual assets |
| `grid.html`, `flexbox.html`, `position.html` | Smaller layout exercises |

## Scope and status

This is a visual frontend study. Search controls, thumbnails, and navigation elements do not implement a video streaming service, account system, or backend API. No fresh browser, responsive-layout, or accessibility test was performed during this documentation update.
